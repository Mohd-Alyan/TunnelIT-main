Quick Start

1. Install

irm https://tunnelit.example.com/install.ps1 | iex

2. Wake the relay

tunnel-it wakeup

3. Expose your service

tunnel-it expose 5000

5000 is your local application's port.

How It Works

Your Browser
     │
     ▼
Tunnel It Relay
     │ WSS
     ▼
Tunnel It CLI
     │
     ▼
localhost:<PORT>

The CLI creates an outbound persistent WebSocket connection to the relay and forwards HTTP traffic to the local service.

Command Reference

tunnel-it expose <PORT>

Expose a local HTTP service.

tunnel-it wakeup

Wake the configured relay and wait until it is ready.

tunnel-it changerelay <URL>

Change the persistent relay server.

Current default relay: wss://tunnelit-main.onrender.com/ws

You can replace the default relay with another compatible Tunnel It relay. This configuration is stored persistently and survives upgrades.

tunnel-it --help

Show complete CLI help.

Features

  • Reverse HTTP tunneling
  • Persistent WebSocket connection
  • Automatic reconnect
  • Binary request/response forwarding
  • Concurrent request handling
  • Dynamic tunnel IDs
  • Configurable relay
  • Localhost-only forwarding
  • Relay wakeup helper
