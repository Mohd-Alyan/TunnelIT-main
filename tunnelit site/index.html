DOCUMENTATION

Features

Designed from first principles for modern webhooks and API prototyping.

Reverse HTTP tunneling

Expose local endpoints safely without modifying edge routers.

Persistent WebSocket connection

Outbound long-lived channels circumvent strict corporate firewalls.

Automatic reconnect

Exponential backoff reconnection ensures zero dropped developer sessions.

Binary request/response forwarding

Full support for multipart/form-data, buffers, image streaming, and audio payloads.

Concurrent request handling

Multiplex hundreds of simultaneous requests across a unified tunnel link.

Dynamic tunnel IDs

Instant distinct URL endpoints provisioned without naming collisions.

Configurable relay

Point the client to your own self-hosted relay clusters with a single flag.

Localhost-only forwarding

Local traffic remains bounded strictly to internal loopback interfaces.

Relay wakeup helper

Seamlessly awakens sleeping serverless and free-tier infrastructure before ingress starts.
